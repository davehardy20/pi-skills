# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for the teaching workspace.
Use it to ground factual teaching. Do not rely on parametric memory when accuracy
matters.

## Template

```md
# {Topic} Resources

## Knowledge

- [Book: _Example Title_ — Author](https://example.com)
  Foundational source on {area}. Use for: {when this source should be consulted}.
- [Official docs: Example](https://example.com)
  Maintained reference for {tool/topic}. Use for: {specific teaching need}.

## Wisdom / Communities

- [Community: Example forum](https://example.com)
  High-signal community for practitioner feedback. Use for: {when to ask humans}.
- Local: {class, group, mentor, or workplace feedback channel}
  Use for: {real-world feedback or coaching}.

## Gaps

- {Source gap that blocks a future lesson or claim}
```

## Rules

- **High trust only.** Prefer primary sources, official docs, recognized experts,
  peer-reviewed work, and well-moderated communities.
- **Annotate every entry.** A bare link is useless later. Say what it covers and
  when to use it.
- **Separate knowledge from wisdom.** Knowledge sources teach concepts. Wisdom
  sources provide real-world feedback.
- **Prune ruthlessly.** Remove shallow, stale, or off-mission resources.
- **Surface gaps explicitly.** If the mission needs a source you do not have,
  add it under `## Gaps` instead of inventing certainty.
- **Record community preferences.** If Dave opts out of communities, note that
  here or in `NOTES.md` so future sessions do not keep suggesting them.
