# Attribution

Adapted from Matt Pocock's `retro` skill in
[Skills For Real Engineers](https://github.com/mattpocock/skills).

Local source: `~/tools/matt_pocock_skills/skills/skills/engineering/retro/`
at commit `4588b32ecab9ecc9fc8cc6b6c5e7d675b6004b0d`.

The Pi version preserves manual invocation and the improvement categories.
It loads the bundled writing-for-agents guide with `read`, bounds session
inspection, reports evidence and uncertainty, and keeps the retrospective
read-only. Approved implementation goes through Seeds and existing PR gates;
Mulch requires a validated successful outcome. Both implementers and reviewers
remain responsible for coding standards.
